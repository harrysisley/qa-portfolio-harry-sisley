# DemoShop Regression Checklist

Use this checklist after a release or bug fix affecting the customer journey.

## Navigation
- [ ] Logo returns to homepage
- [ ] Desktop navigation links work
- [ ] Mobile navigation opens and closes
- [ ] Footer links work

## Authentication
- [ ] User can register with valid data
- [ ] Duplicate email is rejected clearly
- [ ] User can log in
- [ ] Invalid password shows an error
- [ ] User can log out

## Search and Products
- [ ] Search returns relevant results
- [ ] No-result message is shown correctly
- [ ] Product pages load
- [ ] Product images display correctly
- [ ] Add-to-basket works

## Basket
- [ ] Product can be added
- [ ] Quantity can be increased
- [ ] Quantity can be decreased
- [ ] Product can be removed
- [ ] Total updates correctly

## Checkout
- [ ] Required-field validation works
- [ ] Email validation works
- [ ] Postcode field accepts valid input
- [ ] Checkout remains usable on mobile
- [ ] Confirmation state is clear

## Responsive
- [ ] No horizontal scrolling at common mobile widths
- [ ] Text does not overlap
- [ ] Buttons remain tappable
- [ ] Images scale correctly
- [ ] Forms fit within viewport
