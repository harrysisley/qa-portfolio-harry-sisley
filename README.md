This portfolio demonstrates practical QA skills through structured test documentation, bug reporting, exploratory testing, API testing and basic SQL.

## Portfolio Structure

### 01 - Web QA
A complete sample QA project for a fictional e-commerce website called DemoShop. Includes a test plan, test cases, exploratory testing notes, browser/device matrix and example defects.

### 02 - API Testing
A beginner-friendly API testing project showing how to test CRUD endpoints, status codes, validation and negative scenarios in Postman.

### 03 - SQL
Basic SQL examples useful for QA data validation.

### Templates
Reusable templates for future portfolio projects and real-world testing exercises.

## How I Would Use This Portfolio

For a real application, I would duplicate the templates, replace the fictional DemoShop examples with my own observations, add screenshots or recordings to the evidence folders, and export any Postman collections used during API testing.
